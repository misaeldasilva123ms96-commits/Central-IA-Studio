# Prévias 0.4.0

Capturas reais do aplicativo em Chromium com fixture HTTP identificada no nome do
modelo, documentos sintéticos e ferramentas reais sobre pasta temporária. Nenhum
texto ou tempo da fixture é benchmark ou resposta de um modelo treinado.

A marca foi gerada a partir do conceito e incorporada como asset local. Microfone
não foi incluído porque não há reconhecimento de voz nesta entrega. As opções de
anexos, Internet, Plan/Build e permissões são acréscimos pedidos pelo usuário.

A lateral foi compactada após o teste do usuário: navegação acima do histórico,
rolagem única e menu local de configurações no rodapé.
